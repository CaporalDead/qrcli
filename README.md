# qrcli

> Generate QR codes in your terminal. One standalone binary, zero configuration.

**Status: bootstrapping.** The project is being built in the open — every design
decision, trade-off and pitfall is tracked in the
[issues](https://github.com/CaporalDead/qrcli/issues) and
[pull requests](https://github.com/CaporalDead/qrcli/pulls) of this repository.
